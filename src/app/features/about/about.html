How this site works

The project list comes from the public GitHub API, so a new repository shows up here without anyone editing this site. Curated details — a longer write-up, a demo URL, screenshots, a note about what needs doing — live in a small JSON file alongside the code and take precedence over whatever GitHub reports.

GitHub allows 60 unauthenticated API requests per hour per visitor's IP address, which a public page would exhaust quickly. So a full snapshot is also generated at build time and shipped with the site. If the live call is rate-limited or the network is down, the page renders from that snapshot instead of showing an error, and says so quietly at the bottom of the list.

It's an Angular single-page app styled with Tailwind, with no backend and no analytics. The source is on GitHub like everything else here.
